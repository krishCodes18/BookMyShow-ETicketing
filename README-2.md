## 🎯 Overview

**BookMyShow E-Ticketing System** is a fully functional Python desktop application that replicates the core experience of a real-world ticket booking platform. Built using **CustomTkinter** for a sleek, modern GUI, it allows users to:

- Browse across multiple **event categories**
- Select **dates, times, and seats**
- Generate **unique tickets** with random IDs
- Store and review all **booking records** via CSV

This project was developed as a hands-on learning journey into Python programming, GUI design, file handling, and object-oriented application architecture.

<br/>

## ✨ Features

### 🎭 Event Categories
| Category | Description |
|----------|-------------|
| 🎬 Movies | Browse and book the latest films |
| 🎵 Concerts | Reserve seats for live music events |
| ⚽ Sports | Book tickets for sporting events |
| 🎭 Theatre | Secure spots for stage performances |

### 🎟️ Booking System
- 📅 **Date & Time Selection** — Choose your preferred slot with ease
- 💺 **Seat Booking** — Select the number of seats required
- 👤 **Customer Info Collection** — Capture essential booking details
- 🪪 **Auto Ticket Generation** — Instant ticket creation on confirmation
- 🔀 **Random Ticket ID** — Every booking gets a unique identifier
- ✅ **Booking Confirmation Dialog** — Clear, user-friendly confirmation flow

### 📋 Records & Storage
- 💾 **CSV-Based Storage** — All bookings persisted locally
- 📊 **Booking Records Viewer** — Review all past bookings in-app

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine
- `pip` package manager

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/krishCodes18/BookMyShow-App.git
cd BookMyShow-App
```

**2. Install dependencies**
```bash
pip install customtkinter
```

**3. Run the application**
```bash
python e_ticketing.py
```

> 💡 No additional setup required — the app creates `bookings.csv` automatically on first booking!
